# Code of Conduct

This project is an open engineering and creative-technology space. Contributors are expected to communicate in good faith, critique ideas and implementations rather than people, respect privacy and authorship, and help keep technical discussions useful to builders of different backgrounds.

Harassment, threats, discrimination, deliberate disruption, doxxing, or publishing another person’s private information without permission are not acceptable.

Project maintainers may remove content or participation that repeatedly violates these expectations. Technical disagreement is welcome; personal attacks are not.

When reporting a conduct concern, avoid posting sensitive details publicly. Contact the repository owner through an appropriate private channel when one is available.
